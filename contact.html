VCF Manager

VCF & Contact Manager: editor, penggabung, dan pemisah file kontak VCF online

Aplikasi web gratis untuk mengelola file kontak VCF (vCard 2.1, 3.0, 4.0). Impor dan ekspor VCF, CSV, JSON; gabung dan pisah file; hapus kontak duplikat; normalisasi nomor telepon (+62); konversi format. Semua diproses lokal di browser Anda tanpa upload ke server.
